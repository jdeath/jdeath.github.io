Must Disable CORS in your Browser

  • Windows: Open Command Prompt or PowerShell and run:
    "C:\Program Files (x86)\Google\Chrome\Application\chrome.exe" --user-data-dir="C:\chrome-dev" --disable-web-security "https://jdeath.github.io"
  • macOS: Open Terminal and run:
    open -n -a /Applications/Google\ Chrome.app --args --user-data-dir="/tmp/chrome_dev_test" --disable-web-security "https://jdeath.github.io"
  • firefox:
    Type about:config in the address bar, search for privacy.file_unique_origin, and set it to false.
  • Note: Best to download this file and run locally by dragging into your browser.
    https://raw.githubusercontent.com/jdeath/jdeath.github.io/refs/heads/main/index.html
    Do not browse to other websites when disable CORS
